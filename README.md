# 🥔 Kentang OS

Kentang OS adalah web interaktif simulasi “laptop kentang + sosial media + donation system + mini game” yang dibuat untuk belajar HTML, CSS, dan JavaScript.

Project ini berjalan di GitHub Pages dan bersifat frontend-only (tanpa backend).

---

## 🌐 Demo
https://wiraradikahamizan-pixel.github.io/Kentang-OS/

---

## 🚀 Fitur

- 👤 Login sederhana (localStorage)
- 💬 Social feed (post status)
- 💸 Donation simulator (fake system)
- 📊 Statistik aktivitas user
- 🏆 Achievement system
- ⚠️ Warning page sebelum redirect
- 📦 QR Code redirect ke halaman warning
- 🎮 Mini interaksi UI

---

## 🧠 Tujuan Project

Project ini dibuat untuk:
- Belajar struktur web (HTML, CSS, JS)
- Belajar interaksi DOM
- Belajar penyimpanan data sederhana (localStorage)
- Simulasi aplikasi web sederhana
